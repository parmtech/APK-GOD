Optional AI

Static analysis works without an API key. AI can explain a redacted evidence summary through a provider you configure, including a local compatible model.

Configure APK_GOD_AI_ENDPOINT, APK_GOD_AI_MODEL and, if needed, APK_GOD_AI_KEY on this computer. Preview the exact payload with apk-god ai analysis.json --preview. Run apk-god ai analysis.json --output ai-findings.json only when you want to send it.

AI annotations are kept separate from observed evidence. APK files, source files and raw traffic are excluded from that payload.
